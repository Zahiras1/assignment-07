# Assignment 7 - Inventory Management with Lists and Tuples

This repository contains my work for Assignment 7.

## Description
In this assignment, I created a simple inventory management program for TechElectronics. The program stores product information such as product ID, name, price, quantity, and category using lists and tuples. It also performs operations to manage and analyze the inventory data.

## Files Included
- inventory.py

## What I Practiced
In this assignment, I practiced creating and working with lists and tuples to store data. I used indexing and slicing to access elements, and applied list methods like append(), remove(), pop(), and insert() to modify data. Additionally, I learned how to choose between lists and tuples based on whether the data should be changeable or fixed.
